# 🎁 NFT Gift Scanner

**NFT Gift Scanner** — Telegram-бот для мониторинга NFT-подарков на [Fragment](https://fragment.com/), поиска недооценённых лотов и отслеживания выгодных предложений.

## 📌 О проекте

Проект предназначен для автоматического поиска NFT-подарков, выставленных на продажу по цене ниже ориентировочной рыночной стоимости.

Бот анализирует доступные объявления, сравнивает цены похожих NFT и отправляет пользователям уведомления о потенциально выгодных предложениях.

**Основная цель:** упростить поиск перспективных NFT-лотов и сократить время на ручной мониторинг Fragment.

## ⚙️ Основные возможности

- 🔎 Мониторинг объявлений на Fragment.
- 📊 Анализ стоимости NFT-подарков.
- 💰 Поиск лотов с потенциальной скидкой относительно сопоставимых предложений.
- 🔔 Telegram-уведомления о найденных предложениях.
- 📈 Отслеживание изменения цен.
- ⭐ Система избранных лотов.
- ⚙️ Настройка параметров поиска.

> На этапе MVP бот работает только в режиме мониторинга. Автоматическая покупка NFT не предусмотрена.

## 📊 Принцип работы

1. Получение доступных объявлений с Fragment разрешённым способом.
2. Извлечение характеристик NFT-подарков.
3. Сохранение информации о лотах.
4. Сравнение цен похожих NFT.
5. Определение потенциально недооценённых предложений.
6. Отправка уведомлений пользователям.

**Важно:** оценка стоимости является ориентировочной. Низкая цена объявления не гарантирует прибыль при перепродаже.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/VacPit/Krasno63.git
cd Krasno63
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте `.env` на основе `.env.example` и укажите токен Telegram-бота.

### 5. Запуск

```bash
python -m app.main
```

*Инструкция станет полностью актуальной после реализации соответствующих модулей.*
